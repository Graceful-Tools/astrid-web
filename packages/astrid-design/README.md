# astrid-design

Astrid's design tokens and shared art, generated by
[astrid-core](https://github.com/Graceful-Tools/astrid-core/blob/main/design/README.md)
from its `design/tokens.json` and `design/assets`, and copied here at the revision in `REVISION`.

**Never edit these files.** `tests/styles/design-tokens.test.ts` and
`tests/styles/design-assets.test.ts` fail on a hand edit. A
value changes in astrid-core, and arrives with:

```bash
scripts/sync-design-tokens.sh --rev <astrid-core sha>
```

| File | What |
|---|---|
| `astrid-tokens.css` | CSS custom properties (`--astrid-*`), imported by `app/[locale]/layout.tsx` before the theme stylesheets |
| `tokens.resolved.json` | the same values as data, read by `lib/design/tokens.ts` |
| `checkbox-art.json` | the checkbox's shapes as data (layers `box`, `repeat`, `check`), drawn inline by `components/task-checkbox-art.tsx` |
| `assets/` | astrid-core's `design/assets`: `manifest.json` (each file's sha256 and owner), the four checkbox SVGs and the agent marks. `public/images/ai-agents/*.svg` must hash to the same marks |
| `REVISION` | the astrid-core commit all of them were copied from |

The system is described in [docs/specs/DESIGN_SYSTEM.md](../../docs/specs/DESIGN_SYSTEM.md).
